## 2. 概念

### 2.1 可变对象 vs 不可变对象

Python 里所有变量都是"名字贴在对象上"的引用。对象分两类：

| 类型 | 例子 | 特点 |
| --- | --- | --- |
| 不可变 | `int` `float` `str` `tuple` `frozenset` | 值变了就是新对象，id 会变 |
| 可变 | `list` `dict` `set` 自定义类实例 | 原地修改，id 不变 |

这条差异决定了两件事：**函数传参是引用传递**，以及**默认参数只创建一次**。

### 2.2 浅拷贝 vs 深拷贝

- 浅拷贝：只复制最外层容器，内层元素仍是同一个对象（`copy.copy`、`list[:]`、`dict.copy()`、`[:]`）
- 深拷贝：递归复制所有层级（`copy.deepcopy`）

### 2.3 闭包

内层函数引用了外层函数的局部变量，并且外层函数返回内层函数——外层变量就被"关"在了内层函数里。
要点：读取不需要声明，**修改**需要 `nonlocal`。

### 2.4 装饰器

装饰器本质是"接收函数、返回函数"的高阶函数，`@decorator` 只是语法糖：

```python
@log
def f(): ...
# 等价于
def f(): ...
f = log(f)
```

带参数的装饰器是"三层嵌套"：最外层收参数，第二层收函数，第三层收调用参数。

### 2.5 生成器与迭代器

- 可迭代对象（Iterable）：实现了 `__iter__`
- 迭代器（Iterator）：实现了 `__iter__` + `__next__`
- 生成器（Generator）：函数里有 `yield`，自动成为迭代器

生成器的价值：**惰性求值**，一次只算一个，天然适合处理大数据/流式数据。注意它**只能遍历一次**。

### 2.6 上下文管理器

`with` 保证资源一定被释放。等价于：

```python
mgr = expr
value = mgr.__enter__()
try:
    body
finally:
    mgr.__exit__(exc_type, exc, tb)   # 返回 True 可吞掉异常
```

### 2.7 异常体系

`BaseException` → `Exception` → 具体异常。实际项目里应该定义自己的业务异常，并用 `raise X from e` 保留原始异常链。

## 3. 最小可运行代码

### 3.1 深浅拷贝与默认参数

```python
import copy

nested = [[1, 2], [3, 4]]
shallow = copy.copy(nested)
deep = copy.deepcopy(nested)

shallow[0].append(99)
print(nested)   # ?

deep[1].append(100)
print(nested)   # ?
```

```python
# 经典 bug：默认参数是可变对象
def collect(item, bucket=[]):
    bucket.append(item)
    return bucket

print(collect("a"))   # ?
print(collect("b"))   # ?
```

### 3.2 闭包

```python
def make_counter():
    count = 0
    def counter():
        nonlocal count      # 不加这行会报 UnboundLocalError
        count += 1
        return count
    return counter

c = make_counter()
print(c(), c(), c())   # 1 2 3
```

### 3.3 带参数的装饰器（重点）

```python
import functools
import time


def retry(times=3, delay=0.1, exceptions=(Exception,)):
    """失败自动重试的装饰器。"""
    def decorator(func):
        @functools.wraps(func)          # 保留原函数名/文档，必须加
        def wrapper(*args, **kwargs):
            last_error = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_error = e
                    if attempt < times:
                        time.sleep(delay)
            raise last_error            # 重试耗尽，抛最后一次异常
        return wrapper
    return decorator


@retry(times=2, delay=0.01, exceptions=(ValueError,))
def flaky():
    raise ValueError("boom")
```

`functools.wraps` 的作用：把原函数的 `__name__`、`__doc__` 复制到 wrapper 上，否则调试和框架反射会出问题。

### 3.4 生成器：分批处理

```python
def batch(items, size):
    buf = []
    for item in items:
        buf.append(item)
        if len(buf) == size:
            yield buf
            buf = []          # 注意：新建列表，而不是 buf.clear()
    if buf:
        yield buf


for b in batch(range(5), 2):
    print(b)                  # [0, 1] [2, 3] [4]
```

如果写成 `buf.clear()`，yield 出去的那批会被后续清空——这是非常经典的坑。

### 3.5 上下文管理器

```python
from contextlib import contextmanager
import time


@contextmanager
def timer(name: str):
    start = time.perf_counter()
    try:
        yield
    finally:
        cost = time.perf_counter() - start
        print(f"[{name}] {cost * 1000:.1f} ms")
```

`yield` 之前的代码 = `__enter__`，`yield` 之后的 = `__exit__`（放在 `finally` 里保证异常时也执行）。

### 3.6 异常链

```python
class ToolError(Exception):
    """工具调用失败。"""


def call_tool(name: str):
    try:
        return {"weather": "sunny"}[name]
    except KeyError as e:
        raise ToolError(f"未知工具: {name}") from e   # 保留原始异常链
```

在 Agent 项目里，工具执行失败一定要转成**模型能读懂的**异常信息，而不是把 traceback 直接扔给它。

## 4. 常见坑

1. **默认参数陷阱**：`def f(x, bucket=[])` 的 `bucket` 只在函数**定义时**创建一次，所有调用共享。正确写法 `bucket=None` 然后在函数体里 `bucket = bucket or []`。
2. **浅拷贝陷阱**：`copy.copy` 对嵌套列表无效，`[[...]]` 里层还是共享的。
3. **生成器只能遍历一次**：`gen = (x for x in range(3)); list(gen); list(gen)` 第二次是空列表。
4. **循环里创建闭包**：`[lambda: i for i in range(3)]` 全部返回 2，因为闭包捕获的是变量而不是值，用 `lambda i=i: i` 或 `functools.partial` 修复。
5. **`nonlocal` 缺失**：闭包里对变量赋值，不声明 `nonlocal` 会报 `UnboundLocalError`。
6. **`is` 和 `==`**：`is` 比较身份（id），`==` 比较值。判断 `None` 用 `is None`；`1 is 1` 在 CPython 里因小整数缓存可能为 True，但不该依赖。
7. **异常吞掉**：`except Exception: pass` 会让故障永久静默，在 Agent 服务里等同于"永远查不到为什么答错"。
8. **`finally` 里的 `return`** 会覆盖 `try` 里的返回值，也会吞掉异常，不要这么写。

## 6. 参考答案与自测标准

### 练习 1 答案

输出是 `['a']` 和 `['a', 'b']`，因为 `bucket` 在定义时只创建一次，被所有调用共享。

```python
def collect(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

**自测标准**：能说出"默认参数在函数定义时求值一次"这句话，并能画出两次调用指向同一个 list 的示意。

---

### 练习 2 答案

```python
import functools
import time


def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        print(f"[call] {func.__name__} args={args} kwargs={kwargs}")
        try:
            return func(*args, **kwargs)
        finally:
            print(f"[done] {func.__name__} { (time.perf_counter() - start) * 1000:.1f} ms")
    return wrapper
```

要点：用 `try/finally` 保证函数抛异常也能打印耗时；`functools.wraps` 不能省。

**自测标准**：能解释 `@log_calls` 等价于 `f = log_calls(f)`；能说清 `*args, **kwargs` 为什么必须写。

---

### 练习 3 答案

```python
import functools
import time


def retry(times=3, delay=0.1, exceptions=(Exception,), on_retry=None):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_error = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_error = e
                    if on_retry:
                        on_retry(attempt, e)
                    if attempt < times:
                        time.sleep(delay * 2 ** (attempt - 1))
            raise last_error
        return wrapper
    return decorator
```

**自测标准**：能解释指数退避是为了避免重试风暴（thundering herd）；能说出"重试次数耗尽的异常必须是最后一次的异常，不能吞掉"。

### 练习 4 答案

```python
def paginate(items, page_size):
    page = []
    for item in items:
        page.append(item)
        if len(page) == page_size:
            yield page
            page = []
    if page:
        yield page
```

对比：

- 生成器版：内存只保留一页；对任意可迭代对象（包括数据库游标、文件流）都适用。
- 切片版：`items[i:i+page_size]` 每次创建新列表，但要求对象支持下标和 `len()`；对纯流式数据不适用；切片本身也占内存。
- 生成器版缺点：不可重复遍历；如果调用方中途 break，资源释放依赖生成器的 `close`/GC。

**自测标准**：能说出"生成器是惰性的、单次消费"。

### 练习 5 答案

```python
import os
from contextlib import contextmanager


@contextmanager
def temp_env(key: str, value: str):
    missing = object()
    old = os.environ.get(key, missing)
    os.environ[key] = value
    try:
        yield
    finally:
        if old is missing:
            os.environ.pop(key, None)
        else:
            os.environ[key] = old
```

用哨兵对象 `missing` 区分"不存在"和"值为空字符串"，这是常见细节。

**自测标准**：能解释为什么用 `try/finally`；能说出"`yield` 之前是进入、之后是退出"。

### 练习 6 答案

- 第一个输出 `[2, 2, 2]`。列表推导里的 lambda 捕获的是变量 `i`，循环结束时 `i = 2`。
- 第二个抛 `UnboundLocalError`。`inner` 里有 `x += 1`，Python 编译期就把 `x` 判定为局部变量，于是 `x += 1` 在读取时报未绑定。

**自测标准**：能说出"闭包捕获变量而非值"，以及"赋值语句会让变量变成局部变量"。

## 7. 面试问法

| 面试官可能这么问 | 你要答到的点 |
| --- | --- |
| 装饰器是什么？写一个带参数的 | 先说"接收函数返回函数的高阶函数"，再说三层结构，最后主动补 `functools.wraps` 和 `try/finally` |
| 为什么默认参数不能用 `[]`？ | 定义时求值一次 + 所有调用共享，举 `collect` 例子 |
| 深拷贝浅拷贝区别？ | 外层/内层、`copy` 模块、循环引用 `deepcopy` 用 memo |
| 生成器有什么用？ | 惰性、省内存、流式；主动补"只能遍历一次" |
| `with` 的原理？ | `__enter__`/`__exit__`，异常时 `__exit__` 仍执行，返回 True 吞异常 |
| `is` 和 `==` 区别？ | 身份 vs 值；`None` 用 `is` |

**答题技巧**：每答一个概念，主动补一个"坑"或"我踩过的场景"，面试官会认为你是真写过代码的。
