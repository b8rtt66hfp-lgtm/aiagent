# Agent 开发工程师 · 能力大纲（社招 / 零项目起步）

> 适用对象：只会基础 Python 和数据结构，没有 LLM/Agent 项目经验，目标是社招进入 Agent 开发岗。
> 这份文档只解决一件事：**告诉你这个岗位到底考什么、按什么顺序学、学到什么程度算过关。**
> 后续所有基础内容、练习、项目、简历，都以本文档为索引。

---

## 一、岗位画像：这个岗位在招什么人

一句话定义：

> **把大模型（LLM）从"能聊天"变成"能可靠干活的软件系统"的人。**

它不是算法岗，不要求你训练模型、调参、推导反向传播；它也不是纯后端岗，要求你懂模型的能力边界。

面试官判断你行不行，本质看三层：

| 层次 | 关注点 | 面试里的表现 |
| --- | --- | --- |
| 会用 | 提示词、结构化输出、工具调用能不能跑通 | 能不能写出可运行的最小 Demo |
| 会设计 | 任务怎么拆、状态怎么管、失败了怎么办 | 系统设计题、方案取舍 |
| 能上线 | 延迟、成本、并发、稳定性、可观测 | 项目深挖里的数字和坑 |

**常见误区（提前避开）：**

1. 一上来学 LangChain/LangGraph 的 API —— 你会变成"会调库但讲不清原理"的人，面试一问 ReAct 内部循环就露馅。框架放到后期，先手写。
2. 只学提示词技巧 —— 那是运营岗的竞争区，工程岗考的是系统。
3. 项目只做"能跑" —— 面试官问"并发 100 个请求会怎样""失败了怎么重试""效果怎么衡量"，答不上就等于没做过。

| 维度 | 名称 | 为什么这个岗位需要 | 目标等级 |

- **P1 加分**：会了明显加分，能接住追问。
- **P2 了解**：知道是什么、解决什么问题即可，不深挖。

| 编号 | 知识点 | 优先级 | 验收标准（能做到） |
| --- | --- | --- | --- |

| C2 | 范式：ReAct、Plan-and-Execute、Reflection、Router；Workflow 与 Agent 的边界 | P0 | 面对一个需求，能判断"该用固定流程还是自主 Agent"，并说明理由 |

| C4 | 记忆：短期（上下文管理/摘要/截断）、长期（向量库/结构化）、会话隔离 | P0 | 实现"超长对话自动摘要压缩"，且不丢关键信息 |

## 四、面试考察点清单（面试官视角）

面试通常四轮，每一轮考的东西不同。提前知道"他在找什么证据"。

### 第 1 轮 · 基础筛查（30~45 分钟）

- Python：装饰器手写、深浅拷贝、生成器、`asyncio` 场景题、GIL 是什么、`list` 和 `dict` 的底层
- 数据结构：哈希表冲突、栈/队列应用、时间复杂度口算
- LLM 基础：token 是什么、为什么会幻觉、temperature 怎么调、上下文超了怎么办
- 常见问法："你用过哪些 Agent 框架？"（此时如果只会调 API，会立刻被追问到崩）

### 第 2 轮 · 技术深挖（60 分钟）

- ReAct 的完整循环，让在白板上写伪代码
- 工具调用失败的四种情况（参数错、工具报错、模型选错工具、模型不调用）分别怎么处理
- 多轮对话上下文怎么管理，超过窗口怎么办
- 怎么防止死循环、怎么控制成本和延迟
- RAG：文档怎么切、召回不准怎么调、没有答案时怎么兜底
- 常见问法："如果模型一直调错工具，你怎么排查？"

### 第 3 轮 · 系统设计（60 分钟）

典型题目（都要能画架构 + 讲取舍）：

1. 设计一个企业内部知识库问答 Agent（含权限控制）
2. 设计一个能查数据库、发邮件、建工单的任务型 Agent
3. 设计一个代码助手（读仓库、改代码、跑测试）
4. 设计一个客服 Agent，要求可人工接管

答题框架：**需求澄清 → 整体架构 → 核心流程 → 状态与存储 → 失败与降级 → 评测 → 成本**

### 第 4 轮 · 项目与行为面（45 分钟）

- 你项目里最难的点是什么，为什么难，怎么解决的
- 为什么用 A 不用 B（一定会问替代方案）
- 数据量多大、QPS 多少、延迟多少、准确率多少（**必须有数字**）
- 为什么从原方向转 Agent
- 学习方式、最近在看什么

> 结论：**项目必须有数字、有取舍、有踩坑**，否则这一轮必挂。

### 面试话术提醒

JD 同时要求 LangChain 和 AutoGen 时，面试官大概率会追问：

1. "这两个框架你更偏好哪个？为什么？" —— 要能按"对话式 vs 图式、控制力 vs 灵活性"回答，不要说"都差不多"。
2. "如果不用框架，你能实现吗？" —— 这是**验真问题**。必须先手写项目一，才能接住。
3. "你项目里 Agent 循环是怎么跑的？" —— 答消息追加 + tool_calls + 结果回填，而不是"调了个 API"。

> 结论：**框架要会，但手写循环是底线。** 顺序不能反。
