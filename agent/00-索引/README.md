## 二、怎么用这个仓库

推荐顺序（不要跳关）：

1. 先读 [能力大纲](01-岗位大纲/01-Agent开发工程师-能力大纲.md)，搞清楚考什么。
2. 按 `L0 → L7` 关卡推进，每关先读 `02-基础知识` 对应模块。
3. 每个知识点：读概念 → 手敲代码 → 做练习 → **合上文档复述**。
4. 复述不出来就回去重读，不要往下走。
5. 每关结束在下面进度表打勾，并写一句"这关我学到了什么"。

**最重要的原则：所有代码自己敲一遍。** 看懂 ≠ 会，面试是让你在白板上写。

## 四、文档规范

`02-基础知识` 下每篇文档统一 7 段结构：

```
1. 一句话结论

3. 最小可运行代码
4. 常见坑
```
